# Public demo assets

Reserve `docs/assets/` for manually reviewed public-safe screenshots/GIFs:

- Studio UI with generic filenames and no local paths.
- Interest curve with readable score and threshold labels.
- Highlight selection showing the human review step.
- Rendered Short, only after checking gameplay/music rights and owner approval.

The owner-requested [pipeline GIF](assets/pipeline_bodycam.gif) uses actual working footage, saved model scores, and an existing rendered Short. See [asset notes](assets/README.md). No synthetic gameplay imagery was used. The notebook's embedded images are not approved demo assets. Redact usernames, paths, OAuth dialogs, tokens, account metrics and private source filenames before adding a capture. Media rights and permission to publish must be reviewed separately.

`docs/local/` is ignored and holds local audit reports. See [release review](RELEASE_REVIEW.md), [dataset provenance](DATASET.md) and [dependencies](DEPENDENCIES.md).
