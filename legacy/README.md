# Historical workflow

These batch scripts and `phonk_fps.py` represent earlier editing experiments. The supported path is **Studio + harness**; they are not invoked by that pipeline. Their content is preserved for reference, including old relative paths and assumptions. Do not run them from this directory expecting the current preset; moving them did not modernize or validate them.

`local/` is ignored and stores private preservation copies such as the notebook with its original outputs. Production plans and history remain at their original `harness/` paths, ignored by Git, so current local operation and duplicate tracking continue to work.
